# שכולם מאושרים - Android / Galaxy

גרסת Android לאפליקציית תזכורת תפילה לגלקסי.

## מה האפליקציה עושה

- מציגה בגדול: "שכולם יהיו מאושרים ושמחים".
- מוסיפה: "מכל העולם, מכל היצורים".
- מאפשרת לבחור 3 זמני תזכורת ביום: בוקר, צהריים, ערב.
- כל זמן ניתן להפעלה או כיבוי.
- אפשר לבחור ימים מותאמים לכל תזכורת, לשכפל אותה או למחוק אותה.
- בכל תזכורת מתקבלת התראה עם מנגינה עדינה.
- התזכורות נקבעות מחדש אחרי הפעלה מחדש של הטלפון.
- בהתקנה הראשונה יש מסך הגדרה מהירה ובדיקת תקינות להרשאות ולהתראה הקרובה.
- הנגן נשאר במקום שבו הייתם במסך; אפשר לסיים אותו בלחצן "סיים את ההאזנה".
- במצבי קול מונחה ומנטרה האפליקציה משתמשת בקול העברית האיכותי ביותר שמותקן בטלפון, וקוראת את הטקסט האישי שנבחר.
- אפשר לבחור בין פסנתר למדיטציה, חלום רך, או תזכורת ללא מנגינה. אפשר לבחור קטע קצר של 5, 10, 20, 30 או 60 שניות.
- אפשר גם להקליט מילים בקול אישי או לבחור קובץ שמע מהמכשיר; הצליל האישי נשמר רק על המכשיר.

## איך לבנות APK לגלקסי

במחשב הזה כרגע לא מותקן Android SDK או Java Runtime, לכן אי אפשר לייצר כאן APK סופי. כדי לבנות:

1. להתקין Android Studio.
2. לפתוח את התיקייה `HappyPrayerReminderAndroid`.
3. לתת ל-Android Studio לסנכרן Gradle.
4. לבחור `Build > Build App Bundle(s) / APK(s) > Build APK(s)`.
5. להעביר את קובץ ה-APK לגלקסי ולהתקין.
6. בפעם הראשונה לאשר התראות.
7. אם הטלפון מבקש הרשאה לדיוק תזכורות, ללחוץ באפליקציה על "לאשר דיוק תזכורות".

## קובצי צליל

האפשרויות המובנות הן `meditation_piano.mp3` ו־`soft_daydream.mp3` בתיקיית `app/src/main/res/raw/`.
קובצי הצליל הישנים נמצאים בארכיון `removed-audio/` ואינם נכללים באפליקציה.

## הפצת Release חתומה

גרסת הפצה נבנית רק בעזרת מפתח חתימה פרטי שנשמר מחוץ למאגר. הוראות מלאות נמצאות בקובץ `local.properties.example` ובסקריפט `release-and-publish.command`.

להגדרה מקומית אוטומטית ובטוחה של מפתח חתימה, מריצים `./create-release-key.command`. הסיסמה נשמרת ב-macOS Keychain ולא מוצגת.

סקריפט `release-and-publish.command` יוצר גם `HappyPrayerReminder-v1.0.aab` חתום. זה הקובץ שמעלים ל-Google Play Console; משתמשים אינם מתקינים אותו ישירות.
